# Karlsthetics Fitness | Evidence-Based Online Coaching

A responsive, high-converting single-page portfolio website for online fitness coach **Karlsthetics Fitness**.

## Features
- **Evidence-Based Approach**: Highlighted credentials in training, physique competition, nutrition, and physical therapy background.
- **Client Highlights**: Interactive carousel with before & after transformations, category filtering, and image lightbox.
- **The Coaching Difference**: Comparison section illustrating why customized 1-on-1 coaching outperforms cookie-cutter plans.
- **Application Message Builder**: Form-free builder generating personalized messages with one-click copy and direct links to Instagram DM and Facebook Messenger.
- **Visual Identity**: Turf (#0E2A1F) and mustard (#F2B705) visual identity with dark/light mode toggle.
- **Kinetic Wordmark**: Giant two-row footer wordmark with interactive letter-roll animations.

## Deployment
Deployed on Vercel. Built with semantic HTML5, inline CSS, and vanilla JavaScript (no external framework dependencies).
